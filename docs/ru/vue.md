# Компоненты Vue

```ts
import { GanttChart, GanttZoom, GanttLegend } from '@dskripchenko/gantt/vue'
import '@dskripchenko/gantt/style.css'
```

## GanttChart

Таблица строк слева и шкала времени справа, в одной области прокрутки:
таблица и заголовок остаются на месте, пока прокручивается временная шкала.
Диаграмма заполняет высоту родителя; задайте высоту родителю (или диаграмме).

### Свойства

| Свойство | Тип | По умолчанию | |
|---|---|---|---|
| `rows` | `GanttRow[]` | — | Строки и строки групп |
| `links` | `GanttLink[]` | `[]` | Стрелки от конца одной полосы к началу другой |
| `columns` | `GanttColumn[]` | название | Колонки таблицы: `{ key, label, width?, main?, align? }`; `width` — трек сетки (`84px`, `minmax(0, 1fr)`); колонка `main` показывает `row.label`, с неё начинаются названия групп |
| `zoom` | `'day' \| 'week' \| 'month' \| 'quarter'` | `'month'` | Единица колонки |
| `from`, `to` | `ISODate` | вокруг сегодня и данных | Показываемый диапазон; выравнивается по целым колонкам |
| `today` | `ISODate` | сегодня у зрителя | Где проходит линия сегодняшнего дня |
| `showToday` | `boolean` | `true` | |
| `editable` | `boolean` | `false` | Перетаскивание полос, их краёв и вех; клавиши-стрелки |
| `linkable` | `boolean` | `false` | Рисование связей от ручки на конце полосы; Delete удаляет связь |
| `persist` | `(change) => unknown` | — | Сохраняет изменение; отклонённый промис откатывает его |
| `rowHeight`, `barHeight`, `headerHeight` | `number` | `40`, `20`, `48` | Пиксели |
| `tableWidth` | `number` | `360` | Пиксели |
| `compactBelow`, `compactTableWidth` | `number` | `640`, `150` | При ширине диаграммы меньше этой в таблице остаётся только главная колонка |
| `weekStartsOn` | `number` | `1` | 0 — воскресенье … 6 — суббота |
| `locale` | `string` | локаль кита | `en`, `ru` или язык хоста |
| `labels` | `Partial<GanttLabels>` | — | Замена любой строки |
| `ariaLabel` | `string` | "Timeline" | |

### События

- `change(change: GanttChange)` — каждое изменение, которое делает человек,
  включая отмену и повтор.
- `error({ change, error })` — `persist` отказал; изменение откачено.
- `open({ kind: 'bar' | 'milestone' | 'row', id, rowId })` — щелчок без
  перетаскивания, Enter на полосе или вехе либо щелчок по главной ячейке.

### Слоты

- `cell` `{ row, column, value }` — ячейка таблицы (бейдж статуса, ссылка).
- `group` `{ row }` — название строки группы.
- `header-cell` `{ column }` — заголовок колонки.
- `empty` — показывается, когда строк нет.

### Доступно снаружи

`undo()`, `redo()`, `canUndo`, `canRedo`, `scrollToDate(date, 'start' |
'center')`, `scrollToToday()`. Диаграмма прокручивается к сегодняшнему дню при
монтировании и при смене масштаба.

### Мышь, касания и клавиатура

- Перетащите полосу, чтобы сдвинуть её, её край — чтобы сдвинуть один конец,
  веху — чтобы сдвинуть её; подсказка показывает даты. Всё привязывается к дням.
- Перетащите от круглой ручки после полосы на другую полосу, чтобы связать их;
  связи с самой собой, дубликаты и циклы отклоняются с уведомлением.
- Перетаскивание пустого фона сдвигает вид (мышью); в остальном прокрутка
  обычная.
- Полосы и вехи — кнопки в порядке табуляции. ← / → сдвигают на день
  (с Shift — на неделю), Alt+← / → двигают конец, Alt+Shift+← / → — начало,
  Enter открывает. Связь в фокусе удаляется клавишей Delete. Ctrl/⌘+Z
  отменяет, Ctrl/⌘+Shift+Z или Ctrl+Y повторяет.
- Диаграмма — это `grid`; имя каждой полосы называет её строку, даты, прогресс,
  оценку и длительность; изменения объявляются в live-регионе.

### Темы

Цвета берутся из токенов кита, поэтому `data-theme="dark"` просто работает.
Переменные `--gt-*` на `.gt` переопределяют их: `--gt-bg`, `--gt-group-bg`,
`--gt-border`, `--gt-line`, `--gt-text`, `--gt-muted`, `--gt-faint`,
`--gt-today`, `--gt-link`, `--gt-focus`, `--gt-radius`.

## GanttZoom

Группа радиокнопок масштабов для `v-model`:

```vue
<GanttZoom v-model="zoom" :zooms="['week', 'month', 'quarter']" />
```

Названия берутся из `labels.zooms` (по умолчанию Weeks, Months, Quarters);
хост, который мыслит диапазонами, передаёт свои: `{ week: 'Month', month: 'Quarter',
quarter: 'Year' }`.

## GanttLegend

```vue
<GanttLegend
  :items="[
    { kind: 'bar', label: 'progress' },
    { kind: 'bar', tone: 'danger', label: 'overdue' },
    { kind: 'estimate', label: 'estimated dates' },
    { kind: 'milestone', label: 'release' },
  ]"
  hint="Drag an edge of a bar to change its dates"
/>
```

## Языки

В пакете есть английский и русский (`en`, `ru`, `LOCALES`). Диаграмма следует
своему свойству `locale`, иначе — локали кита от родительского
`UidLocaleProvider`. Любую строку можно заменить через `labels`; даты и
названия месяцев форматируются через `Intl` на языке диаграммы.
